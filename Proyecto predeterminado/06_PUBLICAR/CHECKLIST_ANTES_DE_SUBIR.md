# Checklist antes de subir

Cada clip, sin excepción. Tarda 20 segundos y evita rechazos.

---

## Derechos

- [ ] Sé de dónde salió el clip (URL original).
- [ ] Sé quién es el autor.
- [ ] Tengo licencia o permiso, o es material propio/CC0/dominio público.
- [ ] El riesgo está anotado: verde / amarillo / rojo.
- [ ] Si es rojo, **no lo subo**.
- [ ] No hay menores, datos privados ni situaciones íntimas.

## Técnica

- [ ] Duración ≤ 10 s (ideal 2-6 s).
- [ ] Peso ≤ 70 MB.
- [ ] Resolución ≥ 360 px de lado corto (ideal 720).
- [ ] Se ve nítido en móvil.
- [ ] No está estirado.
- [ ] No tiene frames negros.
- [ ] No tiene marca de agua, logo de TV ni UI de otra app.
- [ ] El audio (si hay) no tiene copyright.

## Contenido

- [ ] Se entiende en 3 segundos.
- [ ] El pico está al inicio.
- [ ] El final se siente completo.
- [ ] El texto (si hay) se lee sin zoom.
- [ ] No hay nada importante en los bordes.

## Metadata

- [ ] El título describe literalmente lo que se ve.
- [ ] 3-8 palabras.
- [ ] 10-15 tags, todos relevantes.
- [ ] Sin tags de tendencia que no apliquen.
- [ ] Sin errores de ortografía.
- [ ] Incluye inglés si tu audiencia es global.

## Duplicados

- [ ] No he subido este clip antes.
- [ ] No es una variación trivial de otro clip.
- [ ] Si es una variación, tiene una razón real (otra emoción, otro texto, otro corte).

## Registro

- [ ] URL de KLIPY copiada.
- [ ] Fila añadida a `01_DIARIO\REGISTRO_SUBIDAS.csv`.
- [ ] Estado inicial: `pendiente`.

---

## Si algo falla

| Falla | Acción |
|---|---|
| Derechos | Descarta. No lo "arregles" cambiando el título. |
| Calidad | Re-procesa o descarta. |
| Texto | Re-edita o elimina el texto. |
| Tags | Corrige antes de publicar. |
| Duplicado | Cambia la idea, no el título. |

---

> **Regla:** si dudas, no lo subas. Siempre hay otro clip.
