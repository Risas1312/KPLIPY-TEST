# 06_PUBLICAR · LISTOS

Clips que ya pasaron el control de calidad y están esperando subida.

## Antes de subir

- [ ] `revisar_listos.cmd` sin errores.
- [ ] Checklist `CHECKLIST_ANTES_DE_SUBIR.md` completo.
- [ ] Título y tags definidos.
- [ ] Fuente y riesgo registrados.

## Subida

1. `https://klipy.com/create` → **Create Clips**.
2. Sube el MP4 (máx. 70 MB, máx. 10 s).
3. Título literal + 10-15 tags exactos.
4. Publica.
5. Copia la URL al registro.

## Después

Mueve el archivo a `06_PUBLICAR/SUBIDOS` con la fecha o el ID de KLIPY en el nombre.

## Regla

No dejes más de 30 clips aquí. Si se acumulan, para de producir y sube.
